# Event Management Overall Dashboard

Standalone Odoo 19 addon that replaces the action behind the existing **Event Operations > Dashboard** menu with a consolidated dashboard.

The dashboard provides event-scoped or all-accessible-event totals for events, committees, activities, members, guests, registrations, check-ins, badges, and technical incidents. It includes visual activity, invitation, badge, and incident charts, attendance and activity completion rates, and a recent-event readiness table.

Install `event_management_system` first, then install **Event Management Overall Dashboard** from the Odoo Apps screen. Users see data only for events allowed by their existing Event Management access rules. The dashboard uses those visible event IDs before reading aggregate data.
